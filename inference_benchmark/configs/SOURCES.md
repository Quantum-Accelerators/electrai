# Training-config snapshots

These YAML files are **frozen reference copies** of the training configs
that produced the checkpoints used by the benchmark. They're included so
a reviewer can verify — entirely within this PR — that the inference
knobs in `benchmark_inference.py` and `benchmark_resunet_throughput.py`
match what each model was trained with.

These configs are not consumed by any code path here. They are
documentation. They are exempted from this repo's lint policy via
`pyproject.toml`.

## Drift policy

Same as the `inference_benchmark/charge3net/` mirror: do not edit these
files in place; if upstream changes, regenerate the snapshot from a
fresh source. The ResUNet config is regenerated by `scp`'ing from della;
the ChargE3Net configs are regenerated by `cp` from a local clone of
the charge3net repo at the matching commit.

If you find a benchmark number that disagrees with current upstream, the
right move is to (a) verify the snapshot matches what we actually ran,
(b) re-snapshot from upstream, (c) re-run, (d) note the diff in the PR.
